# Privacy Policy for Zetronix

Last Updated: June 2026

Zetronix is a Discord bot that provides moderation, utility, automation, logging, and server management features.

## Data Collection

Zetronix may process the following Discord data:
- Server IDs
- Channel IDs
- User IDs
- Role IDs
- Message content (only when required for bot functionality)
- Member and presence data for enabled features

## How Data Is Used

Data is used only for:
- Bot commands
- Moderation systems
- Anti-spam systems
- Logging systems
- Welcome/leave systems
- Autorole systems
- Activity and presence features

## Data Storage

Zetronix does not sell or share user data with third parties.

Some server-related configuration data may be temporarily stored to provide bot functionality.

## User Privacy

Message content is only processed when necessary for commands, moderation, or automation features.

## Data Removal

Server administrators may request removal of stored server configuration data by contacting the bot support team.

## Contact

For support or privacy concerns, contact the Zetronix support server.
